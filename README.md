
# Smart Route Finder

A C++17 DSA project for finding shortest routes
using graph algorithms.

## Algorithms
- Dijkstra's shortest-path algorithm
- A* search (zero heuristic in the current version)

## Concepts
- Graphs and adjacency lists
- Priority queues
- Greedy shortest-path search
- Path reconstruction
- STL and file organisation

## Build
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp Graph.cpp -o routefinder

## Run
Windows: routefinder.exe
